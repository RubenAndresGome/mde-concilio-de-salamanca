# Concilio de Salamanca

Usar la implementación instalada como router económico:

1. Ejecutar `propose_dogma` para órdenes múltiples y pedir decisión ante contradicción.
2. Elegir `--audit-level 0|1|2|3`; usar `1` por defecto en automatización.
3. Ejecutar `context_sieve`, `security_diff`, `test_impact` o `debug_evidence` sólo si el contexto lo requiere.
4. Ejecutar `run_audit`; no autorizar frontera sin decisión explícita.
5. Mostrar veredicto, voto, evidencia, uso, caché, parada y escalamiento.

Consultar las referencias de la distribución `concilio_salamanca/reference/` sólo bajo demanda. No mostrar `cave-protocol` al usuario.
