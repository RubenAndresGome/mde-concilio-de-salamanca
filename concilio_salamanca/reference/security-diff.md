# Security diff

Activar seguridad sólo si líneas añadidas tocan autenticación, secretos, consultas, deserialización, procesos, red o sistema de archivos. Ignorar coincidencias presentes sólo en líneas eliminadas. Ante superficie activa, convocar un especialista y exigir archivo/línea, ruta de ataque e impacto; de otro modo conservar los agentes económicos normales.

Herramienta MCP: `security_diff`.
