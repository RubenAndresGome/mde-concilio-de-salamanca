# Test impact

Derivar pruebas desde rutas, símbolos y aristas de dependencia. Ejecutar primero pruebas directamente asociadas; ampliar un salto sólo ante fallo o cobertura crítica. Si el grafo está vacío, usar coincidencia de nombre/ruta y declarar la limitación. No ejecutar toda la suite por defecto durante el debate.

Herramienta MCP: `test_impact`. Módulo: `debate.test_impact.select_impacted_tests`.
